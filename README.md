БИБЛИОТЕЧНАЯ СИСТЕМА УЧЕТА АБОНЕНТОВ
====================================

Описание проекта
---------------
Данный проект представляет собой информационную систему для учета абонентов библиотеки, реализованную на C++ с использованием Windows Forms. Система позволяет вести учет читателей библиотеки, их персональных данных и статуса.

Функциональные возможности
-------------------------
1. Управление данными абонентов:
   - Добавление новых абонентов
   - Удаление существующих записей
   - Редактирование информации
   - Поиск по номеру читательского билета

2. Хранение информации об абонентах:
   - ФИО
   - Год рождения
   - Пол
   - Кафедра
   - Номер группы
   - Должность
   - Статус перерегистрации
   - Наличие книг на руках
   - Дата регистрации

3. Визуализация данных:
   - Отображение информации в табличном виде
   - Диаграмма соотношения студентов и сотрудников

4. Работа с файлами:
   - Загрузка данных из текстового файла
   - Сохранение данных в текстовый файл

Техническая реализация
---------------------
1. Структура проекта:
   - Class.h/cpp - классы для работы со списком абонентов
   - MyForm.h/cpp - основная форма приложения
   - MyForm1.h/cpp - стартовая форма
   
2. Используемые технологии:
   - C++/CLI
   - Windows Forms
   - Однонаправленный связный список для хранения данных
   
3. Архитектура:
   - Реализован паттерн MVC
   - Данные хранятся в связном списке
   - Интерфейс реализован через Windows Forms
   - Взаимодействие с файловой системой через StreamReader/StreamWriter

Системные требования
-------------------
- Windows 7/8/10
- .NET Framework 4.7.2
- Visual Studio 2019 или новее для разработки
